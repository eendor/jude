# Jude Gonzaga | Portfolio

Portfolio of Jude Vincent C. Gonzaga, video editor and graphic designer.

A hand-built version of his Canva portfolio: plain HTML, CSS and a little JavaScript, no frameworks
and no build step. Animations are in `style.css` (keyframes) and `motion.js` (scroll triggers).

## Preview locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000/.
